Umbrella HQ Home Assistant

Umbrella HQ Home Assistant is a privately operated, non-commercial Home Assistant installation. It is not a public service, product, or company. This page exists so that anyone who encounters the app name during a Google sign-in or permissions screen can see what it is.

What it does

The installation connects the owner's own Google Nest devices to a Home Assistant instance the owner controls. It uses Google's Smart Device Management API and Google Cloud Pub/Sub to read device state and events and, depending on the permissions granted, to send commands such as thermostat adjustments. The data is used for household automation and nothing else.

Who can use it

Only the owner and members of the owner's household. There is no public sign-up, no payment, no account creation, and no form on this site that collects information.

Affiliation

This is an independent personal installation. It is not operated by, endorsed by, or affiliated with Google or the Home Assistant project. Google Nest, Google Cloud, and Home Assistant are named only to describe what the installation connects to.

Privacy

The privacy notice describes what data may be processed, where it is kept, and how access can be revoked.

Contact

Questions about this app go through the public issue tracker at github.com/mimen/home-assistant-app-info/issues. Issues are visible to everyone, so do not include addresses, account details, device identifiers, or other private information.
